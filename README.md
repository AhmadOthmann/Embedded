# Embedded Systems

Embedded systems projects and experiments — microcontroller programming, real-time control, and hardware interfacing.

## Focus Areas

- **Microcontroller Programming** — ESP32, STM32, Arduino
- **Communication Protocols** — I2C, SPI, UART, CAN
- **Real-Time Control** — PWM, interrupts, timers
- **Sensor Integration** — IMU, encoders, proximity sensors
- **Actuator Control** — DC motors, servos, stepper motors

## Technologies

- **C / C++**
- **PlatformIO / Arduino IDE**
- **ESP-IDF**
- **STM32CubeIDE / HAL**

## About

This repository collects embedded systems work from coursework and personal projects at TUM and beyond. Projects range from simple GPIO exercises to real-time sensor fusion and motor control.
